Description du projet

Description

Le projet réalisé durant mes stages chez SCR Informatiques consiste au développement d'une application mobile de gestion d'établissements destinée aux commerciaux de l'entreprise. L'application permet de rechercher, consulter, noter et recommander des hôtels et restaurants visités lors des déplacements professionnels.


Le projet a été développé principalement avec React Native et Expo afin de proposer une application mobile moderne, ergonomique et compatible Android. Durant la deuxième année, le projet a été repris afin d'être modernisé, stabilisé et enrichi avec de nouvelles fonctionnalités comme la géolocalisation, la carte interactive et les interactions natives du téléphone.

Contexte

Ce projet a été réalisé dans le cadre de mes stages de BTS SIO option SLAM au sein de SCR Informatiques.


Lors du premier stage, l'objectif principal était de découvrir l'environnement professionnel du développement mobile et de participer à la création d'une première version de l'application. Une phase importante d'autoformation aux technologies React et React Native a été nécessaire avant de commencer le développement.


Lors du second stage, le projet a été repris afin de poursuivre son évolution technique.


Le projet a été réalisé en binôme avec un autre stagiaire, sous la supervision du tuteur de stage Baptiste Coconnier, dans une organisation inspirée des méthodes Agiles avec un suivi des tâches via Wrike.

Objectifs

  • Développer une application mobile professionnelle permettant la gestion d'établissements
  • Permettre aux utilisateurs de rechercher et filtrer des hôtels et restaurants
  • Offrir une interface moderne et ergonomique adaptée au mobile
  • Mettre en place une carte interactive avec géolocalisation
  • Intégrer des fonctionnalités natives du téléphone (appel, mail, GPS)
  • Assurer la communication entre le front-end mobile et une API
  • Produire une version APK fonctionnelle testable sur Android

Fonctionnalités implémentées

  • Développement des interfaces mobiles en React Native
  • Navigation entre les écrans
  • Affichage et gestion des établissements
  • Connexion à une API et base de données PostgreSQL
  • Mise en place d'un système de notation
  • Stabilisation et mise à jour du projet
  • Création d'un système de filtres réutilisables
  • Développement d'une recherche avancée
  • Intégration d'une carte interactive avec géolocalisation
  • Ajout des fonctionnalités natives (appel, mail, GPS)
  • Génération d'une version APK Android

Technologies & outils utilisés

  • Outils de développement : Visual Studio Code, GitHub
  • Développement mobile : React Native, Expo, TypeScript, React
  • Back-end & API : Fastify, Express, Prisma, TanStack Query, Zod
  • Base de données : PostgreSQL
  • Gestion de projet & conception : Wrike, Figma
