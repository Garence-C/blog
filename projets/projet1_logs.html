Description du projet

Description

Conception et mise en place d'une solution complète pour le traitement, l'intégration et l'analyse de journaux d'accès web (logs). Ce projet allie le développement de scripts d'automatisation en Python et l'administration système/réseaux sous environnement Linux.

Contexte

Les serveurs web (comme Apache) génèrent quotidiennement d'énormes fichiers textes appelés "logs", contenant toutes les requêtes des utilisateurs. L'objectif de ce projet était de créer des outils pour parser ces fichiers complexes et les transformer en données statistiques intégrables dans une base de données sécurisée.

Objectifs

  • Configurer une Machine Virtuelle (VM) Linux et l'intégrer au réseau.
  • Déployer un serveur de base de données MariaDB.
  • Développer des scripts Python capables de lire, découper et analyser de lourds fichiers textes.
  • Générer dynamiquement des fichiers `.sql` d'insertion de données

Sécurisation & Administration

  • Application du principe du "moindre privilège" en créant des utilisateurs SQL distincts (un accès en lecture seule `utilog`, un accès complet `gestionlog`).
  • Configuration du serveur Apache et de phpMyAdmin pour n'autoriser les connexions distantes que depuis une adresse IP spécifique.

Traitement de données (Python)

  • Générateur de pseudos : Script lisant un fichier texte pour générer automatiquement des pseudonymes basés sur le nom, prénom et âge.
  • Analyseur de requêtes : Script avec menu interactif identifiant les URLs les plus visitées pour chaque adresse IP.
  • Convertisseur : Transformation des lignes de logs bruts en requêtes `INSERT INTO` SQL.

Fonctionnalités implémentées

  • Liste des restaurants : Affichage scrollable de tous les restaurants avec photo, nom et ville
  • Fiche détaillée : Vue complète d'un restaurant (description, adresse, horaires, types de cuisine, galerie photos)
  • Avis et notes : Affichage des critiques utilisateurs avec système d'étoiles et calcul de note moyenne
  • Navigation intuitive : Retour arrière, transitions entre écrans, gestion des erreurs réseau

Technologies & outils utilisés

  • IDE : Android Studio pour le développement mobile
  • Langage : Java Android avec API niveau 21+ (Lollipop)
  • Backend : PHP 7+ pour l'API REST, MariaDB pour la base de données
  • Communication : HttpURLConnection, JSONObject, BufferedReader
  • Gestion de version : GitLab avec branches par itération
  • Maquettage : Canva pour les prototypes graphiques

Compétences Mobilisées

Gérer le patrimoine informatique (Compétence 1)

Recenser et identifier : Configuration d'une machine virtuelle (Rocky Linux) avec un nom d'hôte spécifique (rocky-ZOZIN.btssio182.lan).

Mettre en place et vérifier : Configuration réseau (IP, Masque, Passerelle, VLAN) et test de connectivité avec la commande Ping.

Répondre aux incidents (Compétence 2)

Traiter des demandes : Modification des fichiers de configuration (mariadb-server.cnf, phpMyAdmin.conf) pour autoriser et sécuriser l'accès distant à la base de données depuis une machine personnelle.

Développer la présence en ligne (Compétence 3)

Analyse du fonctionnement : Compréhension et analyse approfondie de la structure des requêtes HTTP (méthodes GET, POST, PUT, DELETE) et interprétation des codes de réponses (200, 404, 500) directement depuis les fichiers de logs générés par le serveur Apache.

Mettre à disposition un service (Compétence 5)

Déployer un service : Installation et déploiement d'un serveur MariaDB fonctionnel.

Gérer les accès : Création de comptes utilisateurs avec une gestion fine des privilèges (création d'un compte utilog en lecture seule et d'un compte gestionlog avec droits d'écriture complets).

Organiser son développement (Compétence 6)

Exploiter des données : Écriture de requêtes SQL complexes utilisant des fonctions d'agrégation (GROUP BY, COUNT) pour extraire dynamiquement les URL les plus visitées de la base.
