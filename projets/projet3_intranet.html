Technologies & outils utilisés

  • IDE : Android Studio pour le développement mobile
  • Langage : Java Android avec API niveau 21+ (Lollipop)
  • Backend : PHP 7+ pour l'API REST, MariaDB pour la base de données
  • Communication : HttpURLConnection, JSONObject, BufferedReader
  • Gestion de version : GitLab avec branches par itération
  • Maquettage : Canva pour les prototypes graphiques

Compétences Mobilisées

Répondre aux incidents et évolutions

Traiter des demandes concernant les applications : Traitement des tickets de développement, ajout de fonctionnalités selon les besoins exprimés (fiche détail, affichage critiques). Utilisation d'un outil de gestion de tickets (GitLab Issues). Communication écrite et orale adaptée. Compte-rendu des actions réalisées dans les rapports d'itération.

Travailler en mode projet

Analyser les objectifs et modalités d'organisation : Analyse du cahier des charges, définition de l'architecture MVC, conception du diagramme UML, planification des itérations. L'organisation projet est explicitée. Les objectifs du projet sont explicités. L'analyse du besoin et de l'existant est pertinente. Planifier les activités : Organisation en sprints, daily scrums, répartition des tâches en tickets GitLab, gestion du backlog et des priorités. Les activités personnelles sont planifiées de façon formelle, l'avancée est documentée. Le projet est documenté et les livrables sont conformes.

Mettre à disposition un service

Réaliser les tests d'intégration et d'acceptation : Tests unitaires de l'API (Postman), tests fonctionnels de l'application mobile, gestion des cas d'erreur réseau. Les tests d'intégration et d'acceptation sont rédigés. Leur exécution est documentée.

Organiser son développement

Mettre en place son environnement d'apprentissage : Comptes-rendus d'itération, documentation des endpoints API, commentaires du code Java et PHP, daily scrums. Maîtrise d'Android Studio (débogueur, émulateur), utilisation de GitLab (branches, merge, issues), Canva pour le design. L'environnement d'apprentissage personnel est délimité et expliqué. Développer son projet professionnel : Développement de composants Android (Activities, Layouts XML), création de l'API REST, classes DAO et métier.
